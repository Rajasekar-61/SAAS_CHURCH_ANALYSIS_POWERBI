# SaaS Subscription Churn Analysis 📊

## 📌 Project Overview

This project analyzes SaaS subscription and customer support data to understand customer response patterns, satisfaction levels, priorities, and resolution performance.

The dataset was cleaned and prepared before creating an interactive dashboard using **Microsoft Power BI**.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization

## 📊 Dashboard

## 🔍 Key Analysis

The dashboard includes:

- Response by Minute
- First Response by Priority
- Satisfaction Score by Year
- Response by Minute by Priority
- Resolution by Satisfaction Score
- Resolution by Time
- First Response by Time
- Year-wise response analysis

## 📈 Key Metrics

- Total Responses: **177K**
- Total Resolution: **72K**
- Total Satisfaction Score: **5K**

## 🧹 Data Cleaning

The raw SaaS dataset was cleaned and prepared before visualization to improve data quality and make it suitable for analysis in Power BI.

## 🎯 Project Objective

The objective of this project is to analyze SaaS customer support data and present meaningful insights through interactive Power BI visualizations.
